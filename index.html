Projects

ZeuraCore, a multiplayer airline simulation

Own project · Aug 2021 to Jul 2024 · Luau, Node.js, Express, MongoDB

The server and client code behind a multiplayer game where players check in, clear security, board and fly, while staff run the airport with in-game tools. Around 100 files and over 10,000 lines of my own code.

  • Client-server architecture with the server in charge: every staff-only request is checked against a central permission service, so the client is never trusted.
  • Event-driven services. The flight service publishes changes and the screens, gates, check-in desks and in-flight systems subscribe, which keeps them decoupled.
  • Player, moderation and flight data stored in MongoDB behind a REST API that I wrote with Node.js and Express, called over HTTPS with a separate API key per endpoint.
  • Hosted that API on my own VPS, set up from the UNIX command line with secured server ports, SSL certificates and a domain name.
  • An automatic queue system for the check-in desks, purchase receipt handling that alerts staff when a payment fails, and batched, throttled autosaves.
  • Built and sold airport systems like these to other developers on commission.

Code: zeura-core-public-showcase on GitHub
